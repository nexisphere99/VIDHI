## THE MECHANISM   THE CHITRAGUPTA MANUSCRIPT

**Origin:** An incomplete palm-leaf manuscript discovered in the B.J. Medical College library's rare Sanskrit collection   donated decades ago when a nearby ashram was demolished for a road-widening project. Catalogued as "Chitragupta Tantra   Fragment, ca. 14th century, Nath Sampradaya." Nobody's read it in forty years.

**Discovery:** Meera, barred from leaving the hostel, spends time in the library. She reads Sanskrit (Bharatanatyam training included shloka recitation). She finds the manuscript in a forgotten drawer while looking for an anatomy reference. The text describes *deha-vinimaya*   body exchange   as a tantric siddhi.

**The Ritual:**
- **Location:** The old Pataleshwar Cave Temple courtyard   1500-year-old rock-cut temple, quiet at dawn, accessible to both colleges. Later: hostel terrace at midnight (riskier, but closer).
- **Requirements:**
  - Both participants sit facing each other
  - A shared red thread (kalava) tied on both right wrists
  - Turmeric-kumkum circle drawn on ground between them
  - Specific 16-syllable mantra chanted 108 times in unison
  - Duration: ~20 minutes
  - Swap-back: Same ritual, same mantra reversed
- **Timer System:** A brass bell (from the temple)   when struck thrice and mantra chanted once, instant swap-back. Functions like a "panic button." Range: ~2 km. Battery equivalent: the bell's resonance weakens with use.
- **Degradation Rule:** Every swap weakens the "barrier" between consciousnesses. After ~50 swaps, the barrier is paper-thin. After ~70, swaps become spontaneous. After ~80, permanence is inevitable.

## TWINE SUGARCUBE GAME STRUCTURE

### Dual-Protagonist System
```
START → Character Select Screen
         ├── "Play as ARJUN" → Arjun's perspective
         └── "Play as KAVYA" → Kavya's perspective

Each day has passages for BOTH characters.
Player can switch mid-day at designated "SWITCH POV" points.
Some scenes are LOCKED to one POV (intimate scenes, solo moments).
Some scenes are SHARED (both present   player picks whose internal monologue to follow).
```

### Objective System   Per Character Per Day

Each day presents **3-5 objectives** per character. Completing objectives earns points toward relationship/comfort/skill meters. Failing objectives raises suspicion meters.

**Example Day 3 Objectives:**

*Arjun (in Kavya's body):*
- ☐ Survive hostel morning bathroom queue without blowing cover
- ☐ Attend Anatomy lecture and take believable notes
- ☐ Spend time with Meera (relationship +5)
- ☐ Avoid Priya's questions about "why you smell different"
- ☐ BONUS: Successfully wear a saree for hostel event

*Kavya (in Arjun's body):*
- ☐ Navigate Arjun's PG room without Rohit getting suspicious
- ☐ Attend Data Structures lecture (CS skill +5)
- ☐ Handle Arjun's mother's phone call convincingly
- ☐ Ride Arjun's Pulsar without crashing
- ☐ BONUS: Fix Rohit's laptop coding error
